Connect.in – Job Portal Website (Frontend Only)
📌 Project Overview

Connect.in is a demo job portal website developed as a second-year frontend project using HTML, CSS, and JavaScript.
The website simulates how real job portals like Naukri or LinkedIn work, allowing users to browse jobs, apply, upload a resume, write a cover letter, and take a short job-suggestion quiz.

⚠️ Note: This is a frontend-only project — no backend or database is used. All data is static and stored in HTML/JS files.

✨ Features
🏠 Home Page

Displays all job cards.

Each card has:

Job title

Company

Description

Apply Now button

📄 Apply for Job

Users can:

Upload their resume (file upload UI)

Write a cover letter

Submit an application (demo action only)

💼 Jobs Section

Simple list of available job titles.

📝 Take Your Quiz

Contains a 5-question quiz.

Based on answers, a suitable job suggestion is shown.

📘 About Page

Describes the purpose of the website.

📞 Contact Page

Shows contact details such as:

Phone

Email

Social media IDs

WhatsApp broadcast link

👥 Our Team

Shows team members behind the project.

🗣️ Feedback Page

Simple feedback form to collect user opinions.

🧰 Technologies Used

HTML5 – Structure

CSS3 – Styling

JavaScript – Interactivity

Frameset Layout (for header, menu, content, animation, footer)

🚀 How to Run

Download or clone the project.

Open login in your browser.

Login and it will redirect to the website

📌 Limitations

Since this is frontend-only:

Applications are not actually saved.

Resume upload works only visually (no server storage).

Feedback data is not stored.

Quiz suggestions are handled purely in JavaScript.
